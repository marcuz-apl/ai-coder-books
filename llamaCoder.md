# LlamaCoder

**LlamaCoder** (also styled as Llama Coder) refers to an open-source project most likely:

### LlamaCoder (llamacoder.dev) — by Together AI

- **What it is:** An open-source web app that generates full mini-applications from a single text prompt, similar to Claude Artifacts.
- **Key tech:** Powered by **Meta's Llama 3.1 405B** model, hosted on **Together AI** for inference. Uses **Sandpack** for code sandboxing and is built on **Next.js** with Tailwind CSS.
- **Purpose:** Allows anyone to describe an app idea in plain language and get a working React app with a live preview — no coding expertise required.
- **URL:** [llamacoder.dev](https://llamacoder.dev) / [llamacoder.together.ai](https://llamacoder.together.ai)
- **Adoption:** Used by over 1 million users.
